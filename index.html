    $ / unit = $ value of 1 point (or pip) for 1.00 lot. Check your broker's contract size. Tap a field to change it.

    NameUnit$ / unit
      How to find the $ per point
      1. 1 point here = a move of 1.0 in price (NAS100 18500 → 18501, gold 2400 → 2401). For forex, 1 pip = 0.0001 (0.01 for JPY pairs).
      2. In MT5: Market Watch → right-click the pair → Specification → Contract size.
      3. $ per point = contract size × 1.0. Gold 100 → $100. NAS100 1 → $1 (some brokers use 10 or 20). Forex 100,000 × 0.0001 → $10 per pip.
      4. Check with a closed trade: profit ÷ (points × lot) should give the same number.
      5. Pairs not ending in USD (e.g. GBPJPY) change with the rate: use an average, or type the exact PnL from MT5 in the trade form.

      Stopped trading a pair? Tap 🙈 to hide it. Its old trades stay in your history and stats. Pairs with no trades can be deleted with ×.

            GitHub sync

            Saves your data to your private repo so it's safe and the same on every device.

            How to make a token
            1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
            2. Name it "Daily Tracking". Set expiration (1 year is fine).
            3. Repository access: Only select repositories → pick daily-tracking-data.
            4. Permissions → Repository → Contents: Read and write.
            5. Generate, copy it, paste it above. Never share it with anyone.
